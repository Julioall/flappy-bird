# Recursos visuais e sonoros

Este repositório **não redistribui** os sprites ou áudios de Flappy Bird publicados por terceiros. Consulte a página de origem: https://kosresetr55.itch.io/flappy-bird-assets-by-kosresetr55

Para uso local **com permissão adequada**, crie estas pastas na raiz deste repositório:

```text
assets/
├── imagens/
│   ├── background-day.png
│   ├── base.png
│   ├── pipe-green.png
│   ├── yellowbird-downflap.png
│   ├── yellowbird-midflap.png
│   ├── yellowbird-upflap.png
│   ├── gameover.png
│   └── message.png
└── sons/
    ├── wing.ogg
    ├── point.ogg
    ├── hit.ogg
    └── die.ogg
```

Os scripts de cada etapa apontam para `../../assets/...`. O jogo ainda exibe formas básicas no Canvas quando não encontra as imagens, mas a versão com sprites depende dos arquivos baixados pelo professor.

Os direitos dos recursos de terceiros permanecem com seus respectivos autores. **A licença MIT do código não cobre essas imagens ou esses sons.**
